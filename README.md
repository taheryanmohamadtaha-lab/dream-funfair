# شهربازی رؤیایی (Dream Funfair) — نسخه 1.0.0
تولیدکننده: مجید طاهریان

## ساخت APK با GitHub
1. یک مخزن (Repository) جدید در GitHub بسازید.
2. همه فایل‌های این پوشه (lib، tool، pubspec.yaml، .github و ...) را در آن آپلود کنید.
3. به تب **Actions** بروید؛ ساخت به‌صورت خودکار شروع می‌شود (حدود ۵ تا ۱۰ دقیقه).
4. پس از سبز شدن، وارد آن اجرا شوید و از بخش **Artifacts** فایل `dream-funfair-apk` را دانلود کنید.
5. فایل zip را باز کنید و `app-release.apk` را روی گوشی نصب کنید.

## ساختار
- `lib/core` : متن‌ها (فارسی/انگلیسی) و ذخیره‌سازی
- `lib/screens` : اسپلش، منو، انتخاب کاراکتر، تنظیمات، درباره ما، پارک
- `lib/widgets` : رسم کاراکترها
- `lib/game` : (در بخش‌های بعدی) موتور Flame و وسایل بازی

## صدا
فعلاً صدا بی‌صدا پیاده شده است. بعداً فایل‌ها را در `assets/audio/` بگذارید.
